# COVID-19 Analysis Dashboard
This repository contains a Power BI project focused on analyzing the global impact of the COVID-19 pandemic. The dashboard provides detailed insights into confirmed cases, active cases, recoveries, and fatalities across countries and regions. It is designed to present key trends and enable data-driven decisions for policymakers, researchers, and health organizations.

## Overview
The Power BI dashboard explores COVID-19 data globally and regionally, highlighting critical metrics such as:

Total Confirmed Cases
Active Cases
Recovered Cases
Deaths
New Cases

## Key Features

#### Global Overview:
Total confirmed cases, recoveries, deaths, and active cases.
Visualization of data at a worldwide level to understand the scale of the pandemic.

#### Regional Breakdown:
COVID-19 cases segmented by WHO regions (e.g., Western Pacific, South-East Asia, Europe).
Analysis of recovery and death rates in different regions.

#### Country-Specific Insights:
Active cases and recoveries for countries with the highest impact, including the US, Brazil, India, and Russia.
Day-wise case trends for detailed tracking.

#### Interactive Visualizations:
Heatmaps and bar charts to compare metrics across countries and regions.
Filters for region and country selection for focused analysis.

## Tools Used
Power BI Desktop: For creating the dashboard and visualizations.
Data Modeling: Leveraging relationships and measures to generate insightful reports.

## Key Insights

The United States has the highest number of active cases globally.

Brazil and India show strong trends in recoveries despite high case counts.

Regional disparities in death rates and recoveries provide opportunities for targeted interventions.

Month-wise trends highlight the evolution of the pandemic over time.

## Conclusion
This dashboard serves as a comprehensive tool for analyzing the COVID-19 pandemic. It offers detailed insights into the progression and impact of the virus across the globe, empowering stakeholders with actionable data.
